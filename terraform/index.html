How this page reached your browser

No one clicked through the Azure portal to build this. The page you are reading was shipped by a pipeline, from a Git commit to a public URL, in about two minutes.

Code committed Terraform files pushed to Azure Repos — webapp.tf, backend.tf, variables.
Pipeline triggered Azure Pipelines runs init → validate → plan → apply on a hosted Ubuntu agent.
Identity verified Workload identity federation — no stored secrets. State is locked in Azure Storage.
Site published Terraform creates the storage account, enables static hosting and uploads this page to $web.

What the platform is built to do

Storage administration

Blob containers, file shares and managed disks with lifecycle rules that move data from hot to cool to archive, soft delete and immutable retention for records that must not change.

Governance and access

Azure Policy enforces tagging and allowed regions; role-based access keeps every identity on least privilege; resource locks protect what must not be deleted.

Backup and recovery

Recovery Services vaults, geo-redundant storage and tested restores, so a regional outage is a drill the team has already run.

Cost and capacity

Budgets with alerts, orphaned-resource sweeps and right-sized tiers, reported monthly so spend never surprises anyone.
